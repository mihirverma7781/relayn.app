# Project agent instructions

Before making UI changes, read `design.md` and `branding.md` in this directory. `branding.md` is the source of truth for RelayN’s name, voice and product promises. `design.md` maps that identity to the design system and includes Stitch references, reusable components, native-video constraints, accessibility rules and verification workflow.

Preserve real Tauri/libVLC playback when changing the interface. Keep new UI additions consistent with the design tokens and patterns in `design.md`, and update that document when intentionally extending them.
